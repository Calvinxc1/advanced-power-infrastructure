# Advanced Power Infrastructure

Advanced Power Infrastructure expands Factorio 2.0 and Space Age power generation and storage progression with additional boilers, steam engines, steam turbines, heat exchangers, heat pipes, nuclear reactors, fusion power, solar panels, and accumulators.

Fluid pipe and pump infrastructure is handled by the optional Advanced Fluid Infrastructure integration. When that mod is installed, power machines expose matching pipeline extent information. When it is absent, this mod remains standalone and uses power-focused recipe and technology fallbacks without adding AFI-style pipe-length progression.

Electric grid infrastructure is handled by the optional Advanced Energy Grid integration.

This is an early public 0.1.x release. The mod loads and basic progression is implemented, but balance values and long-running save upgrade paths should still be treated as experimental.
