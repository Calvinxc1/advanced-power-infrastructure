# Advanced Power Infrastructure

Advanced Power Infrastructure expands Factorio 2.1 + Space Age power generation and storage progression with additional boilers, steam engines, steam turbines, heat exchangers, heat pipes, nuclear reactors, fusion power, solar panels, and accumulators.

The mod focuses on power generation and storage. Electric grid infrastructure is handled by the optional Advanced Energy Grid companion mod. Fluid pipe and pump infrastructure is handled by the optional Advanced Fluid Infrastructure companion mod. When Advanced Fluid Infrastructure is installed, power machines expose matching pipeline extent information; when it is absent, this mod remains standalone.

This is an early public 0.2.x release. The mod loads and basic progression is implemented, but balance values, long-running save upgrade paths, and broad compatibility with other power mods should still be treated as experimental.
